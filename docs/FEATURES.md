# ميزات مدار وحدودها

| الميزة | الحالة في هذه النسخة | التوضيح |
| --- | --- | --- |
| مراقبة حسابات X | متاحة بعد إضافة حساباتك | المستودع لا يضيف حسابات تلقائيًا. |
| تسجيل مساحة بالرابط | متاحة | يتحقق التطبيق من المساحة ومضيفها قبل تخصيص الالتقاط. |
| التقاط الصوت والصورة | متاح | ملفات المصدر محفوظة محليًا، مع فحص للمقاطع وسبب توقف الالتقاط. |
| نسخة MP4 وصورة مصغرة | مهمة خلفية | القراءة العادية لا تشغّل FFmpeg؛ الواجهة تعرض حالة التجهيز. |
| تفريغ الكلام | متاح عند توفر محرك التفريغ | يوضح الفرق بين نص جاهز، عدم رصد كلام، والانتظار أو الفشل. |
| تحليل النص | متاح بعد التفريغ | يعرض ملخصًا وموضوعات وأسئلة ومؤشرات مراجعة مع قيود واضحة. |
| فصل المتحدثين | اختياري | يحتاج عاملًا منفصلًا ورمز وصول للنموذج؛ قد تبقى المهام في الانتظار. |
| الاستوديو والخط الزمني | متاح | النص مرتبط بالتوقيت، مع تشغيل وتنزيل ملفات الترجمة. |
| حالات النظام والمهام | متاحة | فحص صحة، تقدم المهام، استعادة بعد إعادة التشغيل، ونسخ احتياطي قبل النشر. |

## الشاشات

1. **الرئيسية:** ملخص تشغيلي، التنبيهات، المساحات الأخيرة، وروابط الإجراءات.
2. **المباشر والتسجيل بالرابط:** متابعة المساحات الحالية وطلبات التسجيل.
3. **المكتبة:** البحث والفرز وفصل حالة الملف عن حالة التفريغ والتحليل.
4. **الاستوديو:** مشغل وتفريغ وخط زمني وتحليل وشواهد.
5. **الحسابات:** إضافة الحسابات ومتابعة الأولوية والحالة.
6. **المعالجة وصحة النظام:** أسباب الانتظار والفشل والإجراء التالي.

## تشغيل العامل الاختياري

عامل فصل المتحدثين موضوع في Docker profile مستقل. يتطلب موافقة شروط النموذج وإعداد `HF_TOKEN` محليًا في `.env` ثم تشغيل العامل وفق `docker-compose.yml`. لا تنشر الرمز في Git أو في لقطات الشاشة. راجع واجهة صحة النظام للتأكد من heartbeat وحالة المهام قبل وصف النتائج بأنها مكتملة.
