# الخصوصية والبيانات

هذه نسخة نشر نظيفة بدأت بسجل Git جديد. تضم الشيفرة والاختبارات والوثائق العامة فقط.

**ما لم يُنشر:** قاعدة البيانات، الحسابات المراقَبة، التسجيلات، التفريغات الفعلية، جلسة متصفح X، ملفات `.env`، رموز الوصول، وسجلات التشغيل الخاصة. كل صورة في README ناتجة من بيانات اختبار مؤقتة لا تتصل بحسابات أو تسجيلات الإنتاج.

يحفظ التطبيق بياناته محليًا في مجلد التخزين وأحجام Docker. قبل مشاركة نسخة جديدة، راجع الملفات المضافة بالأمر `git status --short` وتأكد من عدم ضم مسارات البيانات أو الصور الفعلية. لا تضع كلمات مرور أو cookies أو tokens في بلاغات GitHub.

**الحسابات في البرنامج:** قائمة الحسابات المراقَبة إعداد محلي يختاره المشغّل؛ ليست حسابات دخول. يبدأ المستودع دون قائمة حسابات. حذف حساب مراقَب من قاعدة التشغيل لا يحذف تسجيلاته تلقائيًا.
